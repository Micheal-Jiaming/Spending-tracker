# Spending Tracker: Milestone 1
My app answers: which category did most of my money go toward this month?

Files: data/spending.csv (date, category, amount), spending.py (functions), question.ipynb (answers)

How to run: open question.ipynb and choose Restart and Run All.
It prints two self-checks, then three answers:
1. Which category did most of your spending go toward this month?
2. Which do you spend more on: groceries or dining out?
3. Comparing October and November, in which month did you spend more?
